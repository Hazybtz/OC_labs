# Игра 'Быки и коровы'

## Описание проекта 
"Быки и коровы" — это классическая игра-угадайка, в которой игрок должен угадать четырехзначное число, задуманное программой. Каждое число состоит из уникальных цифр. После каждого предположения, игроку сообщается количество "быков" (точные совпадения по позиции) и "коров" (цифры есть, но на других позициях).

## Инструкция по запуску
1. Убедитесь, что на вашем компьютере установлен компилятор C++, командой:
g++ --version 
2. Склонируйте репозиторий:
git clone https://github.com/Hazybtz/OC_labs.git
3. Перейдите в папку проекта:
cd OC_labs
4. Скомпилируйте программу:
g++ bulls_and_cows.cpp -o bulls_and_cows
5. Запустите игру:
./bulls_and_cows
